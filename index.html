vanilla.penplotter

A drawing written in JavaScript goes straight to the pen.
This library works out the route, lifts the pen as little as it can, and drives the plotter from the browser.

Two Libraries

This one does the thinking. The other one lets you use it from p5.js. Take whichever matches how you draw; both end at the same pen.

  1. thisvanilla.penplotter

    The engine. It knows how big your sheet is, in millimetres. It tidies your drawing up, works out the shortest route for the pen, tells you how long the plot will take, and talks to the machine. Plain JavaScript, nothing else needed. Take this if you draw with your own code, with Paper.js, from an SVG file, or want to build something of your own on top.

  2. sisterp5.penplotter

    Three commands for p5.js. You draw as you always do, plot.line() instead of line(), and plot.go() sends your sketch to the pen. It does no thinking of its own; it uses this engine. Take it if you sketch in p5.js. p5.penplotter →

One Plan

Your code draws in millimetres, the size of the real sheet. From that drawing the engine makes one plan. That one plan is what the preview shows, what the numbers describe, and what the pen draws. There is no second version that can differ.

import { PlotterEngine } from "./vanilla.penplotter.js";
import { EbbDriver, createWebSerialTransport } from "./src/driver/ebb.js";

const plot = new PlotterEngine({ units: "mm", page: { width: 210, height: 297 } });
plot.circle(105, 145, 48);
plot.hatch(polygon, { spacing: 2.4 });

const plan = plot.plan({ strategy: "nearest" });
console.log(plan.stats);              // paths, travel, pen lifts, minutes

const transport = createWebSerialTransport();
await transport.open();               // from a click
await new EbbDriver({ transport, profile: "idraw-hse-a2" })
  .run(plan, { confirmed: true });

Five Stages

Use the whole engine, or only the part you need. Each one is a file of its own.

  1. 01Geometry

    Your lines, circles and curves, or an SVG file. Hatching and dots to fill a shape. Moving, turning and scaling. All in millimetres.

  2. 02Optimizer

    Tidies up: joins lines whose ends touch, throws away what was drawn twice, takes out points that change nothing.

  3. 03Planner

    Puts the lines in a good order so the pen travels as little as possible, draws some of them backwards, chooses where a circle starts, and keeps each pen's lines together.

  4. 04Renderer

    Shows the plan on a canvas before anything moves. For other plotters it writes the plan as SVG, HPGL or G-code, the files those machines read.

  5. 05Driver

    Talks to the machine. First without moving, to check every command; then for real, speeding up and slowing down smoothly. Tested on one plotter: an iDraw HSE / A2, from Chrome or Edge. Direct plot →

Get Started

Load it with one line. Draw in millimetres. Plot from a click.

import { PlotterEngine } from "https://cdn.jsdelivr.net/gh/seb-prjcts-be/vanilla.penplotter@v0.3.1/vanilla.penplotter.js"; const plot = new PlotterEngine({ units: "mm", page: { width: 210, height: 297 } }); plot.line(20, 20, 190, 20); plot.circle(105, 145, 52); const plan = plot.plan(); plot.drawRoute(canvas.getContext("2d"));
