JavaScript plotter engine · v0.2.0

Code becomes
motion.

You write a drawing in JavaScript. The engine works out the route, lifts the pen as little as it can, and sends the whole thing to your plotter from the browser. No SVG, no vpype, no Inkscape in between. Those stay available for other machines; they are no longer the road.

Two libraries, one direction

The engine, or the p5 face on it.

  1. thisvanilla.penplotter

    The engine. It holds the geometry, cleans it up, plans the pen's route, estimates the time and drives the machine. Plain JavaScript, no dependencies, no p5.js. Take this if you draw with your own code, with Paper.js, from an SVG, or want to build your own layer on top.

  2. sisterp5.penplotter

    Three methods on p5.js. You draw as you always do, plot.line() instead of line(), and plot.go() sends the last frame to the pen. It contains no engine of its own; it calls this one. Take it if you sketch in p5.js. p5.penplotter →

Vanilla first

No canvas capture.
No SVG detour.

The sketch builds plot geometry in millimetres, and the same plan feeds the preview, the statistics and the driver. What you see on screen is what the pen does.

import { PlotterEngine } from "./vanilla.penplotter.js";
import { EbbDriver, createWebSerialTransport } from "./src/driver/ebb.js";

const plot = new PlotterEngine({ units: "mm", page: { width: 210, height: 297 } });
plot.circle(105, 145, 48);
plot.hatch(polygon, { spacing: 2.4 });

const plan = plot.plan({ strategy: "nearest" });
console.log(plan.stats);              // paths, travel, pen lifts, minutes

const transport = createWebSerialTransport();
await transport.open();               // from a click
await new EbbDriver({ transport, profile: "idraw-hse-a2" })
  .run(plan, { confirmed: true });

One job, five independent stages

Use the whole engine.
Or take one gear.

  1. 01Geometry

    Paths, SVG, hatches, stipples and transforms, all in physical units.

  2. 02Optimizer

    Join ends that touch, drop what was drawn twice, simplify and resample.

  3. 03Planner

    Order the paths, reverse the ones that allow it, move the seam of closed shapes, schedule the pens.

  4. 04Renderer

    Preview the plan on a canvas; for other machines, write it as SVG, HPGL or G-code.

  5. 05Driver

    Dry-run the command list, then stream the plan to the machine. Tested on one: an iDraw HSE / A2 over Web Serial. Direct plot →
