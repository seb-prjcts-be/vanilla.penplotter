A Line and a Circle

This is complete. One import, a page in millimetres, two shapes, and the route the pen will take, drawn on any canvas.

import { PlotterEngine } from "https://cdn.jsdelivr.net/gh/seb-prjcts-be/vanilla.penplotter@v0.3.1/vanilla.penplotter.js";

const plot = new PlotterEngine({ units: "mm", page: { width: 210, height: 297 } });
plot.line(20, 20, 190, 20);
plot.circle(105, 145, 52);

plot.drawRoute(canvas.getContext("2d"));   // the pen's route, red where it travels
console.log(plot.plan().stats);            // paths, metres, minutes

change one thing and look

One Change

A fill, an order, a file. Each one shows you something about the pen.

  1. 01add a hatch

    plot.hatch([{ x: 30, y: 200 }, { x: 180, y: 200 }, { x: 180, y: 270 }, { x: 30, y: 270 }], { spacing: 2.4 }): a dark rectangle made of lines. Change 2.4 to 1.2 and it is twice as dark, and twice as long to plot.

  2. 02keep your order

    plot.plan({ strategy: "drawn" }): the pen draws in the order you wrote, and the minutes go up. That is the price of order; the chaos game pays it on purpose.

  3. 03bring a file

    Paste an SVG in SVG to pen and pick a width: the same drawing, from a file.

put it on paper

On Paper

Every example page has a pen panel: it shows the bed, lets you place and turn the sheet, counts the minutes, and remembers where a stopped plot can resume.

  1. 01Chrome or Edge

    With the plotter on USB. Web Serial lives nowhere else.

  2. 02Home corner

    Slide the carriage to the home corner by hand, and put the paper down.

  3. 03Connect, then Plot

    Choose the plotter in the list that opens, check the bed drawing, press Plot.

  4. 04Stop

    The pen comes up, the motors let go. Resume later from the stroke where it stopped.

Tested on one machine: an iDraw HSE / A2 with EBB firmware 3.0.2. No plotter? Everything above works without one, and the same plan comes out as SVG, HPGL or G-code for any other machine.

under the hood

Under the Hood

You give it shapes in millimetres, or an SVG. It tidies them up, finds the shortest route for the pen, shows you that route, counts the minutes, and drives the plotter. For another machine it writes the same drawing as SVG, HPGL or G-code. Plain JavaScript, nothing else to install.
