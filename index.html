try it

A Line and a Circle

This is complete. One import, a page in millimetres, two shapes, and the route the pen will take, drawn on a canvas you supply.

import { PlotterEngine } from "https://cdn.jsdelivr.net/gh/seb-prjcts-be/vanilla.penplotter@v0.3.1/vanilla.penplotter.js";

const plot = new PlotterEngine({ units: "mm", page: { width: 210, height: 297 } });
plot.line(20, 20, 190, 20);
plot.circle(105, 145, 52);

plot.drawPreview(canvas.getContext("2d"), { showTravel: true });   // the pen's route, red where it travels
console.log(plot.plan().stats);            // path count, distances and a time estimate

change one thing and look

One Change

A fill, an order, a file. Each one shows you something about the pen.

  1. 01add a hatch

    plot.hatch([{ x: 30, y: 200 }, { x: 180, y: 200 }, { x: 180, y: 270 }, { x: 30, y: 270 }], { spacing: 2.4 }): a dark rectangle made of lines. Change 2.4 to 1.2 and the lines sit closer together. The patch gets denser and usually takes longer to plot.

  2. 02keep your order

    plot.plan({ strategy: "drawn" }): the pen draws in the order you wrote, and the route stays in input order. This can take more travel; the chaos game keeps its order on purpose.

  3. 03bring a file

    Try a supported SVG in SVG to pen and pick a width: the same drawing, from a file.

put it on paper

On Paper

Every example page has a pen panel: it shows the bed, lets you place and turn the sheet, counts the minutes, and remembers where a stopped plot can resume.

  1. 01Chrome or Edge

    With the plotter on USB. Web Serial lives nowhere else.

  2. 02Home corner

    Slide the carriage to the home corner by hand, and put the paper down.

  3. 03Connect, then Plot

    Choose the plotter in the list that opens, check the bed drawing, press Plot.

  4. 04Stop

    Stop requests a pen lift and motor release. The panel can resume after the last completed stroke of the same drawing, once you park the carriage at home again.

Direct plotting has been tested on an iDraw HSE / A2 with EBB firmware 3.0.2. Without hardware you can preview and export SVG, HPGL or G-code. Those files need software and settings suited to the receiving machine.

under the hood

Under the Hood

You give it points in physical units or supported SVG shapes. It can clean up paths, choose nearby strokes, preview the route and estimate its duration. The EBB driver sends a complete plan to the tested iDraw HSE / A2. SVG, HPGL, G-code and JSON exports are also available. Plain JavaScript ES modules.
