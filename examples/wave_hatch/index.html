vanilla.waves · hatch · tone

Wave hatch

Seventy cells on an A4 sheet. Two waves decide each one: how far apart the hatch lines are, and at what angle. Where the lines crowd the paper goes dark, where they thin out it stays light. No grey anywhere, only strokes. About ten metres of ink, seven minutes of plotting.

Core snippet
const spacing = tone.sample(column * 1.9 + row * 1.1, 0);  // 1.3 … 6.5 mm
const angle = turn.sample(column * 0.8 + row * 2.3, 0);    // 0 … π
plot.hatch(cell, { spacing, angle });
