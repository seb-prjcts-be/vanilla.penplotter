Layers · tools · one pen change

Two pens

Every layer names its pen. The engine draws everything for the black fineliner first, then lifts, holds the motors and waits for you to put in the red brush pen. One stop, no guessing which line was which. If you take the plan to another machine instead, HPGL gets pen 1 and pen 2 and the SVG keeps a group per pen.

Core snippet
plot.layer("arcs", { toolId: "black" });
plot.arc(62, 150, 40, -1, 1);
plot.layer("wedge", { toolId: "red" });
plot.hatch(wedge, { spacing: 2.2 });
