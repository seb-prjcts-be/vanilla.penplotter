# vanilla.penplotter v0.5.0

2026-10-05

Adds a DrawCore driver for the A3 H. A drawing plan can now move the pen through GRBL, with explicit machine bounds, Z heights and axis directions. The driver waits for the controller to report idle before finishing.

Adds controller recognition. The connection reads the version response and selects EBB or DrawCore. The mechanical model and pen settings remain part of your configuration. Plain GRBL and unknown controllers stop before movement.

Adds the A3 H hardware record: DrawCore V2.09, a 10 mm line and square, pen movement, a 1 mm pen-up move and return to the work origin. These small tests passed on 2026-10-05 using the development bundle. Larger drawings, stopping during motion and hardware failure recovery still need physical tests.

Keeps the EBB driver and its HSE/A2 tests. The new connection also sends EBB stop commands after a communication timeout. DrawCore stop requests feed-hold; the pen can stay down and queued movements can stay paused. DrawCore sessions and automatic resume are not implemented.

Updates Setup, Guide and the plotter list with the connection and settings. DrawCore command research used cfloutier’s drawcore_plotink utilities and extracted iDraw extension configuration; the documentation links to both.

Validation: core tests, EBB queue regression, DrawCore serial simulations and the pinned waves integration. The p5.penplotter 0.3.0 bundle includes this core. Existing release tags remain unchanged.
