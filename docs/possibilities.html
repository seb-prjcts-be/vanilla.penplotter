Possibilities · v0.2.0

What a pen can do.

A plotter has no pixels, no grey, no fill. It has one line at a time, a pen you can swap, and all the time in the world. I find that a good set of limits to draw inside. Everything below is drawn live by the engine in this page; take each one as a starting point, not a feature list.

plot.hatch() · plot.crossHatch()

Tone from lines

Grey does not exist; density does. Hatch spacing in millimetres is the only tone control a pen respects, and it is honest: 6 mm reads light, 1 mm reads dark, and a second pass at right angles goes darker still. Let a wave, a noise field or an image decide the spacing per cell and you have a tonal drawing.

for (const [index, spacing] of [6, 4, 2.6, 1.7, 1.2].entries()) {
  plot.hatch(cell(index), { spacing, angle: Math.PI / 4 });
}
plot.crossHatch(cell(5), { spacing: 1.2 });

plot.stipple({ count, minDistance, seed })

Dots that never collide

A stipple is a quarter-millimetre dash, placed by a seeded generator that keeps a minimum distance. The same seed gives the same dots tomorrow, on paper. Vary the count per region and the sheet gets a grain.

plot.stipple(band, { count: 900, minDistance: 1.4, seed: 7 });

plot.tool() · plot.layer() · penMap

Pens as layers

A tool is a pen: colour and width. A layer names its tool. The planner finishes one pen before asking for the next, HPGL gets pen numbers from a map, SVG gets one group per layer with the pen colour in its metadata. Three pens, one plan, two stops.

plot.tool({ id: "blue", color: "#385a86", width: 0.5 });
plot.layer("sky", { toolId: "blue" });
plot.exportHPGL({ penMap: { black: 1, blue: 2, red: 3 } });

plot.plan({ strategy: "nearest" })

Routes that shrink

Left: strokes drawn in the order the sketch produced them, pen-up travel in red. Right: the same strokes, reordered and reversed by the planner. The drawing is identical; the plot is minutes shorter. Every example on this site is planned this way.

plot.plan({ strategy: "input" }).stats.travelDistance;    // long
plot.plan({ strategy: "nearest" }).stats.travelDistance;  // short

Geometry.importSVG() · transformDocument()

Files in

Paths, lines, polygons, rects, circles and nested transforms come in from any SVG, curves flattened at a tolerance you choose. So a p5.plotSvg capture, an Inkscape drawing or a p5.gysin plotter-SVG can be fitted onto the bed, planned and plotted here, without leaving the browser.

const doc = Geometry.importSVG(svgText, { curveSteps: 24 });
const fitted = Geometry.transformDocument(doc, Geometry.Matrix.scale(0.3));

exportHPGL() · exportGCode() · compileEbbPlan()

        
One plan, four machines

        
The plan is the contract, and the EBB command list is what I actually send. The other three are the side door: HPGL for a vintage HP or Roland plotter, G-code for a GRBL machine with a servo, an SVG for AxiDraw's own software. Same route, same order, same seams, whichever way it leaves.

        
plot.exportHPGL({ unitsPerMm: 40 });
plot.exportGCode({ penUp: "M5", penDown: "M3 S1000" });
compileEbbPlan(plot.plan(), { profile: "idraw-hse-a2" }).commands;

      

    


    

      

      

        
any function of x · p5.waves · vanilla.waves

        
A number in, a line out

        
The engine only wants points. Anything that returns a number for an x is a drawing: Math.sin, a noise function, or one of the 35 shapes in p5.waves and vanilla.waves. Sample at a fixed time and the animation becomes a sheet; sample at ten times and you have a series.

        
for (let x = 20; x <= 190; x += 0.5) {
  points.push({ x, y: 60 + wave(x) });
}
plot.polyline(points);

seeds · new PlotterEngine() per sheet

        
Series, not singles

        
A plotter makes editions. One rule, one seed per sheet, four engines, four plans, four files with the same name and a number: the workflow of a print run, in a loop.

        
for (const seed of [1, 2, 3, 4]) {
  const plot = build(seed);
  download(`sheet-${seed}.svg`, plot.exportSVG());
}
