Direct plot

A 40 by 25 millimetre frame with two waves inside. It is the drawing I used to check the machine, and a small drawing to try first. Measure the 40 mm width and 25 mm height on paper to check the scale. The dry run lists every command without sending one.

const transport = createWebSerialTransport();
await transport.open();                       // from a click
const driver = new EbbDriver({ transport, profile: "idraw-hse-a2" });
await driver.run(plot.plan(), { confirmed: true });

First job

A hatched shape, its outline and a circle. Enough to watch the engine order separate hatch strokes, and show in red where the pen still has to lift.

plot.hatch(polygon, { spacing: 4.5, angle: Math.PI / 7 });
plot.polygon(polygon);
plot.circle(108, 145, 38);
const plan = plot.plan();

Two pens

Every layer names its pen. The engine draws all the black first, then holds the motors and waits until you have put in the red pen.

plot.layer("arcs", { toolId: "black" });
plot.arc(62, 150, 40, -1, 1);
plot.layer("wedge", { toolId: "red" });
plot.hatch(wedge, { spacing: 2.2 });

Route lab

A drawing with shuffled fragments, duplicates, a 1 440-point circle. Switch each optimizer pass on and off and compare the path count, pen lifts, travel and estimated time.

plot.optimize({ passes: ["deduplicate", "merge", "simplify"] });
const plan = plot.plan({ strategy: "nearest" });
plan.stats.travelDistance;   // 14 421 mm → 546 mm

Waves to pen

This example samples 32 rows from vanilla.waves at t = 0 and plots that still drawing. Try another time to make a different sheet.

const sampler = waves.createSampler({ wave: "triangle sine", range: [-3, 3] });
points.push({ x, y: 40 + row * 7 + sampler.sample(x + row * 2, 0) });
plot.polyline(points);

Wave hatch

Seventy cells; two waves decide each one, spacing and angle. Dark where the lines crowd, light where they thin out. No grey, only strokes: about ten metres of ink.

const spacing = tone.sample(column * 1.9 + row * 1.1, 0);  // 1.3 … 6.5 mm
const angle = turn.sample(column * 0.8 + row * 2.3, 0);    // 0 … π
plot.hatch(cell, { spacing, angle });

SVG to pen

Paste an SVG or choose a file, set the drawing width and inspect the plan. Supported paths and basic shapes can be plotted; SVG text, images, styling, clipping and viewBox mapping are not reproduced.

const imported = Geometry.importSVG(svgText);
const fitted = Geometry.transformDocument(imported, matrix);
for (const layer of fitted.layers) plot.layer(layer.id).paths = layer.paths;
-> full example

Plotting needs Chrome or Edge on localhost or https, and for now one machine: an iDraw HSE / A2 with an EBB board. The wave examples load a pinned vanilla.waves build. If you draw in p5.js, the sister site records supported p5 shapes: p5.penplotter examples.
