vanilla.penplotter Examples

Every one of these ends the same way: connect, confirm, plot. The previews below are the engine running in this page, so what you see is the plan the machine would get. Open an example for the full page and its source. No plotter at hand? Each page can also hand you the plan as SVG, HPGL or G-code; I just did not want that to be the headline.

Direct plot

A 40 by 25 millimetre frame with two waves inside. It is the drawing I used to check the machine, and the one to try first: small, quick, and if the frame measures 40 mm on paper, the scale is right. The dry run lists every command without sending one.

const transport = createWebSerialTransport();
await transport.open();                       // from a click
const driver = new EbbDriver({ transport, profile: "idraw-hse-a2" });
await driver.run(plot.plan(), { confirmed: true });

plot.tool() · plot.layer() · one pen change

Two pens

Every layer names its pen. The engine draws all the black first, then holds the motors and waits until you have put in the red pen. One stop, at the right moment.

plot.layer("arcs", { toolId: "black" });
plot.arc(62, 150, 40, -1, 1);
plot.layer("wedge", { toolId: "red" });
plot.hatch(wedge, { spacing: 2.2 });

plot.optimize({ passes }) · plot.plan({ strategy })

Route lab

Input made as bad as I could: shuffled fragments, duplicates, a 1 440-point circle. Switch each optimizer pass on and off and read what it buys in paths, pen lifts, travel and minutes. The pen gets whatever you settle on.

plot.optimize({ passes: ["deduplicate", "merge", "simplify"] });
const plan = plot.plan({ strategy: "nearest" });
plan.stats.travelDistance;   // 14 421 mm → 546 mm

vanilla.waves · a still from an animation

Waves to pen

vanilla.waves animates; a plotter draws once. So time stops: 32 rows sampled at t = 0 become one sheet. That is the whole trick for plotting anything that moves.

const sampler = waves.createSampler({ wave: "triangle sine", range: [-3, 3] });
points.push({ x, y: 40 + row * 7 + sampler.sample(x + row * 2, 0) });
plot.polyline(points);

vanilla.waves · plot.hatch({ spacing, angle })

Wave hatch

Seventy cells; two waves decide each one, spacing and angle. Dark where the lines crowd, light where they thin out. No grey, only strokes: about ten metres of ink.

const spacing = tone.sample(column * 1.9 + row * 1.1, 0);  // 1.3 … 6.5 mm
const angle = turn.sample(column * 0.8 + row * 2.3, 0);    // 0 … π
plot.hatch(cell, { spacing, angle });

Geometry.importSVG() · transformDocument()

SVG to pen

You already have drawings as SVG, from p5.plotSvg or Inkscape. Paste one, pick a width, and it goes to the pen like everything else here. The detour through vpype and Inkscape is the part I wanted to skip.

const imported = Geometry.importSVG(svgText);
const fitted = Geometry.transformDocument(imported, matrix);
for (const layer of fitted.layers) plot.layer(layer.id).paths = layer.paths;
-> full example
