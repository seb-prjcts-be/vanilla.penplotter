plot.hatch() · plot.polygon() · plot.circle()

First job

The smallest complete job: a hatched polygon, its contour and a circle, optimized, planned and previewed with pen-up travel. No p5.js, no SVG.

plot.hatch(polygon, { spacing: 4.5, angle: Math.PI / 7 });
plot.polygon(polygon);
plot.circle(108, 145, 38);
const plan = plot.plan({ drawSpeed: 35, travelSpeed: 80 });

plot.tool() · plot.layer() · exportHPGL({ penMap })

Two pens

Each layer names its tool. The planner draws everything for one pen before it asks for the next, and the same plan becomes SVG, HPGL with pens 1 and 2, or G-code.

plot.layer("arcs", { toolId: "black" });
plot.arc(62, 150, 40, -1, 1);
plot.layer("wedge", { toolId: "red" });
plot.hatch(wedge, { spacing: 2.2 });
plot.exportHPGL({ penMap: { black: 1, red: 2 } });

plot.optimize({ passes }) · plot.plan({ strategy })

Route lab

Bad input on purpose: shuffled fragments, duplicates and a 1 440-point circle. Switch each optimizer pass on and off and read what it buys in paths, points, pen lifts, travel and time.

plot.optimize({ passes: ["deduplicate", "merge", "simplify"] });
const plan = plot.plan({ strategy: "nearest" });
plan.stats.travelDistance;   // 14 421 mm → 546 mm

vanilla.waves · createSampler() · exportSVG()

Waves to SVG

A fixed-time wave drawing on A4: 32 polylines sampled from vanilla.waves, planned, and exported as an SVG for any plotter software. Nothing moves; the sheet is a still.

const sampler = waves.createSampler({ wave: "triangle sine", range: [-3, 3] });
points.push({ x, y: 40 + row * 7 + sampler.sample(x + row * 2, 0) });
plot.polyline(points);
const svg = plot.exportSVG();

Geometry.importSVG() · transformDocument() · EbbDriver

SVG to pen

Any SVG, from p5.plotSvg or Inkscape, fitted onto the bed, optimized and planned in the browser, then straight to the pen. The road p5.plotSvg stops at, continued without vpype.

const imported = Geometry.importSVG(svgText);
const fitted = Geometry.transformDocument(imported, matrix);
for (const layer of fitted.layers) plot.layer(layer.id).paths = layer.paths;
await driver.run(plot.plan(), { confirmed: true });

compileEbbPlan() · createWebSerialTransport() · EbbDriver

Direct plot

The plan goes from the browser to an iDraw HSE / A2 over Web Serial: dry-run the command list, connect, confirm, plot. Every point is checked against the bed before the first byte. Chrome or Edge.

const transport = createWebSerialTransport();
await transport.open();                       // from a click
const driver = new EbbDriver({ transport, profile: "idraw-hse-a2" });
await driver.run(plot.plan(), { confirmed: true });
Open example →
