About vanilla.penplotter

I wanted to try drawing on my iDraw with JavaScript, and to see the pen’s route before starting the machine.

Why

Keeping the drawing and the plotter connection in one browser page seemed useful. The sketch supplies points and pen assignments; the engine makes a plan you can inspect before plotting.

vanilla.penplotter stores points in layers, with a tool for each layer. It can tidy those paths, choose nearby strokes and estimate how long the drawing will take. You can export the result or run it through the EBB driver. Direct plotting still needs a dry run, a parked carriage and confirmation.

Where it stops

  • Drawing. It has polyline primitives, simple fills and a limited SVG importer. Curves are sampled into points; there is no text layout or polygon boolean support. Draw with p5.js, p5.gysin, Paper.js or plain arrays; hand the points over.
  • p5.plotSvg. p5.plotSvg captures a p5 sketch as an SVG and covers far more of p5's drawing API. It exports the drawing for use in other software. This engine can import supported SVG paths and basic shapes, plan them and plot them. Check the preview: it does not reproduce every SVG feature.
  • vpype. vpype is the mature reference for line sorting, merging and simplification, in Python, on the command line. The optimizer here uses some of those ideas in JavaScript, with fewer options.
  • Other machines. Direct plotting has been tested on the iDraw HSE / A2. For other machines, you can export SVG, HPGL or G-code and use software configured for your plotter.

The machine

Development and physical tests use an iDraw HSE / A2 with EBB firmware 3.0.2. Its CoreXY axes and 80 steps per millimetre were checked on paper on 2026-09-21. The 594 × 432 mm travel comes from the vendor configuration. There is no automatic homing: park the carriage at the home corner before plotting.

The EBB driver checks bed bounds, plans acceleration and handles acknowledgements. On abort or error it attempts to clear motion, lift the pen and release the motors. The example panel can resume after completed strokes of the same drawing; pausing and resuming within a stroke are not implemented.

Using p5.js

If you draw in p5.js, p5.penplotter records supported p5 shapes as you draw them. Planning and machine code stay in this engine. The adapter checks a minimum core version; that check does not prove every possible version combination.

Related work

  • p5.plotterControl: live control of GRBL pen plotters from p5.js.

  • AxiDraw Python API: the reference for reliable EBB motion.
  • p5.gysin and wave samplers: the sister libraries; the first exports SVG whose supported paths can be imported here, the second supplies the numbers the examples draw with.
